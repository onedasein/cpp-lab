# 类与函数进阶

## 运算符重载
运算符重载（Operator overloading）可以让我们用运算符对自定义类型的对象进行某种操作。
## 成员函数与友元函数
非成员函数形式的运算符重载虽然方便，但是也存在缺点

- 无法访问类的私有成员
- 一些运算符只能定义为成员函数，比如下标运算符

this指针与赋值运算符的重载

this指针指向“调用函数的对象”

友元函数 friend关键字
## 构造与析构
当我们需要定义一个对象时，便会给提供初始化。在C++中，构造函数（Constructor）是一种方便的初始化方法；而析构函数（Destructor）能够在对象的生存期结束前对其进行最后处理，尤其是动态内存回收。
